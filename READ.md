# Gesture Controlled Application

A real-time computer vision application that allows users to control system actions using hand gestures.  
Built using **OpenCV**, **MediaPipe**, **Tkinter**, and **PyAutoGUI**.

---

## 🖥 Features

- Real-time webcam feed  
- Hand landmark detection (21 points)  
- Multiple gesture recognition:
  - Thumbs Up
  - Thumbs Down
  - Open Palm
  - Fist
  - Peace
  - Pointing
  - Swipe Left
  - Swipe Right  
- Action Mapping (Volume Up/Down, Play/Pause, Next/Previous, Stop, Hotkeys)
- Settings Panel (Debounce, Swipe Sensitivity, Cooldown)
- JSON-based gesture → action mapping
- No-touch control for media & system
